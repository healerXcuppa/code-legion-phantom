# 🏦 ATM Simulator

A beginner-friendly console-based ATM Simulator built in Python. This project was developed as part of my Python learning journey and demonstrates how real-world problems can be broken into small, reusable functions.

---

## ✨ Features

- 💰 Check account balance
- ➕ Deposit money
- ➖ Withdraw money
- 📜 View transaction history
- ✅ Withdrawal confirmation
- 🛡️ Input validation and error handling
- 🖥️ Clean terminal interface
- ♻️ Reusable helper functions
